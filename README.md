# Bank Management System

## Project Overview
A Java Swing-based Bank Management System developed as part of Project Based Learning (PBL).

## Technologies Used
- Java
- Java Swing
- File Handling
- Object Serialization
- OpenJDK 21

## Features
- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- View transaction history
- Save account information using file handling
- Search and display accounts

## How to Run

Compile:
```bash
javac BankManagementSystem.java
```

Run:
```bash
java BankManagementSystem
```

## Storage
Account information is stored locally using a serialized data file.

## Project Type
Academic Project – Project Based Learning (PBL)
